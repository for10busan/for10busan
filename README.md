# 포텐체대입시 부산교육원 앱 (FOR10 Busan)

학생·학부모·강사가 함께 쓰는 **출결 · 운동일지 · AI 자세 분석 · 입시 관리** 앱입니다.
휴대폰 홈 화면에 설치해서 앱처럼 쓸 수 있어요(PWA).

- **외부 라이브러리 없이** Node.js 22만 있으면 바로 실행돼요. `npm install`이 필요 없어요.
- 데이터베이스(SQLite)와 업로드 영상은 `data/` 폴더 하나에 모두 저장돼요. 이 폴더만 백업하면 됩니다.

---

## 1. 바로 실행해 보기 (내 컴퓨터)

1. [Node.js 22 LTS](https://nodejs.org) 이상을 설치합니다 (22.13 이상).
2. 이 폴더에서:

```bash
npm start
```

3. 브라우저에서 http://localhost:3000 을 엽니다.
4. 처음 실행하면 원장 계정이 자동으로 만들어져요. 터미널에 이메일과 비밀번호가 표시됩니다.
   (기본값 `admin@for10.kr` / `for10admin1`. 처음 로그인하면 새 비밀번호로 바꾸게 돼요.)

### 데모 데이터로 둘러보기

가상 강사·학생·학부모, 반, 출결, 일지, 분석된 영상까지 넣어서 화면을 둘러볼 수 있어요.

```bash
DATA_DIR=./demo-data node --no-warnings scripts/seed.js --demo
DATA_DIR=./demo-data npm start
```

| 역할 | 이메일 | 비밀번호 |
|---|---|---|
| 원장 | admin@for10.kr | for10admin1 |
| 강사 | coach@demo.kr | demo1234 |
| 학생 | student@demo.kr | demo1234 |
| 학부모 | parent@demo.kr | demo1234 |

> 실제 운영용 `data/`에는 데모 데이터를 넣지 마세요.

## 2. 기능

### 원장·부원장·강사
- **홈 대시보드**: 오늘 출결, 이번 달 출석률, 장기 결석자, 직원 출근, 최근 7일 이용 현황, 승인 대기
- **오늘 수업**: 미체크 출결, 확인 대기 영상, 일지 안 쓴 학생
- **반 관리**: 요일·시간·기간을 정하면 수업 일정이 자동으로 생겨요. 휴강·보강, 담당 강사, 학생 배정
- **출석 체크**: 출석·지각·결석·공결 + 사유 메모(학부모에게 알림), "미체크 전체 출석"
- **직원 출근**: 매일 출근/결석과 사유
- **출결 통계**: 반별·학생별, 장기 결석자 기준 설정, CSV 내보내기 (엑셀에서 바로 열림)
- **학생 상세**: 일지 달력, 종목 기록 그래프, 영상, 목표 대학, 모의고사, 합격 예측
- **코치 코멘트**: 일지·영상에 남기면 학생과 학부모에게 알림
- **종목 관리** (7개 탭): 기본 정보, 촬영 가이드(예시 사진 3장), 지표, 기준값(성별·학년별 버전, 초안·발행), 피드백 문구(변수 치환), 중요 포인트(AI 자동 표시 범위), 판정 미리보기
- **대학 관리**: 대학·학과·전형, 실기 종목(순서 지정), **내신 환산표**, **실기 배점표(남/여)**
- **합격선 입력**: 학년도별 합격선·평균·경쟁률
- **순위**: K 열쇠(일지 1개 + 출석 1개, 하루 최대 2개, 매월 초기화) / 월별 실기 테스트 종목별 순위
- **실기 기록 입력**: 월별 실기 테스트 기록을 한 화면에서 입력
- **캘린더**: 실기 테스트·주요 일정(지점별), 학생 생일
- **가입 승인 / 학부모 연결 승인 / 회원 관리**: 역할·지점·나오는 요일, 직원 계정 만들기, 임시 비밀번호 발급, 지점 추가, 영상 보관 기간

### 학생
- 홈(오늘 수업·출석 상태, K 열쇠, 최근 코멘트, 다가오는 일정)
- 운동일지(컨디션·수면·통증·종목별 기록·메모), 기록 추이 그래프
- **자세 분석 영상 올리기** → 휴대폰 브라우저에서 AI가 관절을 찾고 각도를 재요
- 목표 대학(4지망), 내신 입력, 합격 예측(학생부+실기 총점 → 안정/적정/도전), 모의고사

### 학부모
- 자녀 연결 요청(학원 승인 후 열람), 자녀 출결·일지·영상·코멘트 보기, 결석·지각 알림

## 3. AI 자세 분석은 이렇게 동작해요

1. 학생이 옆에서 찍은 영상을 올립니다.
2. **영상 결과 화면을 연 브라우저(학생 휴대폰)** 에서 Google MediaPipe Pose가 프레임마다 관절 17개를 찾아요. 서버에는 관절 좌표만 보내므로 서버 부담이 거의 없어요.
3. 서버가 종목별 알고리즘(`public/js/pose/analyze.js`)으로 핵심 순간(백스윙 탑·도약·착지 등)을 찾고 각도를 계산합니다.
4. 기준값과 비교해 낮음/적정/높음을 판정하고, 피드백 문구를 보여 줘요.
5. 강사는 프레임을 넘기며 **핵심 순간을 직접 지정**하거나 **각도를 직접 재서** 보정할 수 있어요. 이전 결과는 이력으로 남아요.

지원하는 분석 종목: 제자리멀리뛰기, 메디신볼 던지기, 서전트 점프, 좌전굴, 윗몸일으키기, 배근력, 왕복달리기·Z런.
나머지 종목은 "기록 입력형"입니다.

> ⚠️ **중요: 지금 들어 있는 기준값·환산표·배점·합격선은 모두 "예시 값"이에요.**
> 코치진이 확인해서 종목 관리와 대학 관리에서 고친 뒤 "예시" 표시를 해제해 주세요.
> 대학 목록과 대학별 실기 종목도 참고용으로 넣어 둔 것이니 매년 모집요강으로 확인하세요.

MediaPipe 파일은 기본적으로 인터넷(jsDelivr, Google)에서 받아요. 학원 인터넷이 이 주소들을 막는다면
`@mediapipe/tasks-vision`의 `vision_bundle.mjs`와 `wasm/` 폴더, `pose_landmarker_full.task` 모델을 `public/vendor/mediapipe/`에 두고
`.env`에 `MEDIAPIPE_BASE=/vendor/mediapipe`, `MEDIAPIPE_MODEL=/vendor/mediapipe/pose_landmarker_full.task`를 넣으세요.

## 4. 인터넷에 올리기 (배포)

앱은 **디스크(data 폴더)가 계속 남아 있는 서버**에서 실행해야 해요. (Vercel처럼 파일이 사라지는 곳은 맞지 않아요.)
휴대폰 설치(PWA)와 카메라 업로드를 위해 **HTTPS 주소**가 필요합니다.

### 방법 0. 오라클 클라우드 무료 서버 (영구 무료, 추천)
`deploy/oracle-setup.sh` 맨 위 다섯 줄(GitHub 주소, 도메인, DuckDNS 토큰, 원장 이메일·비밀번호)을 바꾼 뒤,
오라클에서 인스턴스를 만들 때 **고급 옵션 → 관리 → cloud-init 스크립트** 칸에 붙여 넣으세요.
서버가 처음 켜질 때 Node.js·앱·https·자동 실행·매일 백업이 모두 설치돼요 (약 10분).
오라클 콘솔의 **VCN → 보안 목록**에서 TCP 80, 443 포트를 열어야 합니다.
앱을 고친 뒤 서버에 반영: 서버에서 `sudo for10-update`. 설치 기록: `/var/log/for10-setup.log`.

### 방법 A. Railway (유료, 가장 쉬움)
1. 이 폴더를 GitHub 저장소에 올립니다.
2. Railway → New Project → Deploy from GitHub → 저장소 선택 (Dockerfile을 자동으로 사용)
3. Volume을 추가하고 마운트 경로를 `/data`로 지정
4. Variables에 `ADMIN_EMAIL`, `ADMIN_PASSWORD` 입력 → 배포 → 생성된 https 주소로 접속

### 방법 B. Fly.io / Render
- Dockerfile 그대로 사용, 영구 디스크(volume)를 `/data`에 연결하면 됩니다.

### 방법 C. 학원 PC·NAS
1. Node.js 22 설치 후 `npm start` (윈도우는 작업 스케줄러로 부팅 시 자동 실행)
2. HTTPS 주소는 [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) 같은 무료 터널로 연결

### 환경 변수 (`.env.example` 참고)

| 이름 | 설명 | 기본값 |
|---|---|---|
| `PORT` | 포트 | 3000 |
| `DATA_DIR` | DB·영상 저장 폴더 | ./data |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` / `ADMIN_NAME` | 처음 만들 원장 계정 | admin@for10.kr / for10admin1 |
| `BRANCH_NAME` | 첫 지점 이름 | 부산교육원 |
| `MAX_VIDEO_MB` | 영상 최대 크기 | 300 |
| `APP_SECRET` | 보안 키 (비우면 자동 생성) | 자동 |

## 5. 백업

`data/` 폴더(= `app.db`, `app.db-wal`, `uploads/`)를 통째로 복사하면 됩니다.
서버를 잠깐 멈추고 복사하는 것이 가장 안전해요. 원본 영상은 보관 기간(기본 90일, 회원 관리 → 지점·운영 설정)이 지나면 자동 삭제되고 분석 결과는 남아요.

## 6. 운영 전에 꼭 할 일
- [ ] 원장 비밀번호 바꾸기, 강사 계정 만들기 (회원 관리)
- [ ] 반 만들기 → 학생 배정
- [ ] 종목별 기준값·피드백 문구·중요 포인트를 코치진이 확인하고 "예시" 해제
- [ ] 목표 대학의 내신 환산표·실기 배점표·합격선 입력
- [ ] 이용약관·개인정보처리방침 문구를 학원에 맞게 수정 (`routes/auth.js`)

## 7. 개발자용

```
server.js            HTTP 서버 (라우팅·세션·CSRF·정적 파일)
lib/                 db(스키마)·auth·html 템플릿·서비스 로직
routes/              화면별 코드
public/js/pose/      AI 분석(analyze.js: 브라우저·서버 공용), MediaPipe 실행(runner.js), 결과 화면(viewer.js)
scripts/seed.js      기본 데이터 / --demo
test/                단위 테스트(npm test), 화면 점검 스크립트(Playwright)
```
